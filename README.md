# rawda-site

Site public de l'application Rawda, hébergé via GitHub Pages.

- `index.html` — page d'accueil minimale
- `privacy.html` — politique de confidentialité (requise par l'App Store / Google Play)
- `terms.html` — conditions générales d'utilisation
- `assets/` — icône, favicon, feuille de style partagée

## URLs

- Le domaine `getrawda.co` n'est pas encore configuré (voir `CNAME`) - en attendant, utiliser l'URL GitHub Pages par défaut :
- Landing : `https://testous3.github.io/rawda-site/`
- Politique de confidentialité : `https://testous3.github.io/rawda-site/privacy.html`
- CGU : `https://testous3.github.io/rawda-site/terms.html`

Une fois le DNS de `getrawda.co` pointé vers GitHub Pages, les mêmes pages seront aussi servies sur `https://getrawda.co/`.
